# YouCoder 0.0.2 更新案内（配布候補）

動画ごとの記録保持、保存失敗の表示と復旧、パネル配置、狭い画面でのタイムライン操作を改善しました。この文面の作成は公開済みを意味しません。実YouTubeのSPA・全画面/シアター・字幕・広告への影響は、Cloudのbot確認により未検証です。

## 更新前に記録を退避してください

保存権限を `storage` に限定し、通常上限 **10,485,760 bytes** を使用します。旧版で上限を超えた記録がある場合、更新後も記録を自動削除しませんが、保存・編集・旧形式からのコピーが拒否されることがあります。通常画面からの行削除も保存処理なので、容量整理に使えない場合があります。

1. 更新前に、必要な動画のCSVと各ボタンセットのJSONを書き出します。CSVは分析用で、全記録の復元ファイルではありません。
2. 全記録を保全する場合は[バックアップ手順](backup-restore.md)に従い、動画ページと設定編集を止めて全storage JSONを端末内へ退避します。公開Issue等へ貼り付けないでください。
3. 同手順の `chrome.storage.local.getBytesInUse(null)` で容量を確認します。旧 `timelines` のコピーや長いラベルも上限に含まれるため、行数だけでは判断できません。
4. 超過時は元のプロファイルとバックアップを残し、手順の制約を理解した上で不要な動画キー等を整理してから編集を再開します。削除対象を判断できない場合はそのまま保全してください。自動整理、全データ復元、分割復元のUIはありません。

全storageの復元は、自己バックアップを**新しい空プロファイル**へ戻す上級者向け手順です。既存環境へのマージや無条件の一括上書きには使えません。更新・整理・復元の前後で設定と複数動画の記録を確認し、確認が終わるまで元データを残してください。
