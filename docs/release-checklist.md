## 公開を判断する前の残件

- [ ] 最終配布headでfrozen install / 単体テスト / 型検査 / 本番build / 実MV3 fixture / manifest・配布bundle監査の結果を記録する。
- [ ] **実YouTube: BLOCKED**。公開動画はHTTP 200でもbot確認で再生不可（`readyState=0`）。実再生、通常操作、SPAのA→B→A、全画面出入り、シアター、字幕、リサイズ、小画面、表示された広告を覆わないことは未確認。正常な許可済み環境で最小限の公開動画により確認する。ログイン、広告の除去/クリック、動画ダウンロード、制限回避は行わない。fixture合格で代用しない。
- [ ] 375px等でタイムライン右側の横スクロールを含む全操作を手操作で確認する。既存fixtureは主に外枠の収まりを確認している。
- [ ] 移動後のパネル同士の重なりを評価し、許容するか対策するか決める。現状は衝突防止がなく、既存証拠に74pxの重なりがある。
- [ ] `force: true` を使うID保持試験を通常クリックの操作性の証拠に数えない。必要な画面操作を別途確認する。
- [ ] ボタンセットJSONの利用者向け退避→新規プロファイルでの復元、チーム再設定、CSV内容を確認する。ストレージ全体JSONの復元機能は未提供で、手動復元も未検証。Store版などID変更時の移行方針を確定する。
- [ ] `unlimitedStorage` の必要性を実測し、不要なら削除する。既存権限を維持したことだけで最小権限審査を完了扱いにしない。
- [ ] 保存時暗号化、サイトと共有する配置ストレージ、コンソールへの設定値ログを含め、privacy説明と公開時の保護要件の整合を確認する。
- [ ] Storeのデータ分類と利用認証を発行者が最終確認する。privacy文書を正式版にし、匿名で読めるURLを確認する。
