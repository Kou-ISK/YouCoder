# GitHubからYouCoderを使う

デスクトップ版Chrome向けの試用版です。配布ZIPには動作に必要なファイルが入っているため、Node.js、pnpm、ターミナルでのビルドは不要です。Chrome Web Storeの開発者登録や料金も、この手動導入には必要ありません。

実YouTubeでの最終検証は未完了です。最初は重要な記録を持たないChromeプロファイルで試してください。会社・学校が管理するChromeで開発者モードを使えない場合は、管理者の方針に従ってください。

## ダウンロードと導入

1. **[YouCoder 0.0.2 の配布ZIP](../downloads/youcoder-0.0.2-chrome.zip?raw=true)** をダウンロードします。ZIPのGitHubページが開いた場合は「Download raw file」を押します。「Code → Download ZIP」で得られるのはソースコードです。
2. ZIPを展開します。Windowsでは「すべて展開」、macOSではZIPをダブルクリックします。
3. `manifest.json`、`popup.html`、`static` フォルダなどが入ったフォルダを確認し、書類フォルダ内の `YouCoder` など、今後も使う固定の場所に置きます。`manifest.json` がそのフォルダの直下にあることを確認します。
4. Chromeのアドレスバーに `chrome://extensions` と入力します。
5. 右上の「デベロッパー モード」をオンにし、「パッケージ化されていない拡張機能を読み込む」から手順3のフォルダを選びます。展開前のZIPや一つ上のフォルダは選びません。
6. 一覧に **YouCoder / 0.0.2** が表示されたら、ツールバーのパズル形アイコンからYouCoderを開きます。頻繁に使う場合はピンで固定できます。

Chromeはこのフォルダから拡張機能を読み続けます。導入後に移動・削除したり、ダウンロード整理で消したりしないでください。手順は[Chrome公式の読み込み方法](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)に沿っています。

## 最初の記録

1. YouCoderのポップアップでチームを登録し、サッカー・バスケットボールなどのボタンセットを選びます。アクション名とラベルは編集できます。
2. 通常のYouTube動画ページ（`https://www.youtube.com/watch?v=...`）を開き、動画が読み込まれるのを待ちます。導入前から開いていたページは再読み込みします。
3. プレーヤー下のタグ付けパネルで、対象チームのアクションを押して開始します。進行中にラベルを付け、同じアクションを再度押して終了します。
4. タイムラインに区間とラベルが表示されることを確認します。記録時刻を押すと、その位置へ移動します。
5. 「CSV出力」で、この動画の記録を保存します。別の動画へ移る前に、再読み込み後も記録が残ることを試してください。

動画ごとに別の記録を持ちます。保存処理中は操作が待機状態になります。保存・読み込みのエラーが表示された場合、その操作が保存済みとは考えず、タイムラインの内容を確認してください。

## 権限と保存先

| 権限・保存先 | 用途 |
| --- | --- |
| `https://www.youtube.com/*` の読み取り・変更 | 動画ID・再生時刻の確認、パネル表示、記録時刻への移動 |
| `storage` | チーム・ボタンセット・表示設定・動画別記録をChrome内に保存 |
| 拡張機能の `chrome.storage.local` | 動画ID、記録、設定、移行前のコピー。Chromeプロファイル・拡張機能IDごとに分かれる |
| YouTubeサイトの `localStorage` | パネル位置とサイズ。YouTubeと共有する保存領域 |

全サイト、閲覧履歴API、Cookie、Sheetsへのアクセスは要求しません。現行の配布コードの静的監査では、分析記録を開発者サーバーへ送る処理は見つかっていません。YouTubeやChrome自身の通信まで止めるものではありません。

記録はこのChrome環境に保存され、クラウド同期されません。アプリ独自の暗号化はありません。CSV・JSONも平文なので、端末、保管先、バックアップや共有先の保護を確認してください。詳しくは[データの取扱い](privacy.md)と[保存時保護の確認範囲](storage-protection-assessment.md)を参照してください。

## CSVとJSONの違い

| 出力 | 含むもの | 含まないもの・復元 |
| --- | --- | --- |
| タイムラインの「CSV出力」 | 現在の動画のチーム・アクション・開始/終了秒・ラベル | 動画ID、行ID、他動画の記録は含まない。アプリへ戻すCSVインポートはない |
| ポップアップの「エクスポート」 | 選択中のボタンセット1個 | チーム一覧と分析記録は含まない。「インポート」でボタンセットだけ復元できる |

CSVは `actions_YYYY-MM-DD.csv` という名前で保存されます。動画IDをファイル名などに追記して区別してください。数式として解釈され得る値には先頭に `'` を付けて出力します。

必要なボタンセットはそれぞれJSON出力し、チーム名も控えてください。全データの退避と別の空プロファイルへの復元は[上級者向け手順](backup-restore.md)にあります。全記録の一括バックアップ・復元画面はありません。

## 更新する

GitHub配布版は自動更新されません。READMEで版と検証範囲を確認し、更新する場合は次の順に進めます。

1. 記録操作を止め、必要な動画別CSVと各ボタンセットJSONを保存します。全記録を保全したい場合は[全ストレージの退避](backup-restore.md#全storageの退避上級者向け)も行います。
2. 拡張機能一覧で現在のIDと読み込み元フォルダを控え、今の拡張機能フォルダを別の場所へコピーして残します。このコピーはプログラムの控えであり、分析データのバックアップではありません。
3. YouCoderのポップアップとYouTubeのタブを閉じます。新しい配布ZIPは一時的な別フォルダへ展開します。
4. **読み込み元フォルダ自体とそのパスを残し、中のプログラムファイルだけを新版の内容へ置き換えます。** `manifest.json` が元と同じ位置に来るようにし、古いJS/CSSを混在させないでください。
5. `chrome://extensions` の既存YouCoderで「再読み込み」を押します。「削除」して入れ直す操作は使いません。
6. 版と拡張機能IDを確認し、YouTubeを開き直します。以前の動画の記録と設定を確認してから新しい分析を始めます。

フォルダやプロファイルを変えるとIDや保存領域が変わる場合があります。記録が見えなくても元の拡張を削除せず、IDとプロファイルを確認してください。新版で編集した記録が旧版でも読めるとは限りません。

0.0.1からの更新では、動画を開いたときに旧記録を動画別形式へコピーし、旧コピーも残します。保存上限は設定・旧コピーを含め **10,485,760 bytes** です。旧版で既にこの上限を超えている場合、追加・編集や移行コピーが失敗し得ます。[容量・復元の制約](backup-restore.md#容量と既存の大きなデータ)を更新前に確認してください。

## 困ったとき

| 状況 | 確認すること |
| --- | --- |
| 読み込み時にmanifestが見つからない | ZIPを展開したか、選んだフォルダ直下に `manifest.json` があるか |
| パネルが出ない | YouCoderが有効か、通常の `/watch?v=...` ページか、ページを再読み込みしたか、ポップアップで表示をオフにしていないか |
| 保存・読み込みに失敗する | 操作を止めて既存データを退避する。再インストールやストレージ消去で対処しない。容量、拡張の再読み込み、ページの再読み込みを確認する |
| 別のChromeで記録が見えない | プロファイル・拡張機能IDごとの保存で、同期機能はない |
| JSONを読み込めない | ボタンセットのエクスポートで作ったJSONか確認する。全ストレージ退避JSONやCSVはこの画面では読めない |

不具合は[GitHub Issues](https://github.com/Kou-ISK/YouCoder/issues)へ、版、Chromeの版、再現手順を添えて報告できます。動画ID、チーム名、個人名、分析記録、認証情報が含まれる画像・ログ・JSONはそのまま投稿しないでください。

## 確認済み範囲と制約

配布元コミットとCI結果は[配布記録](../downloads/README.md)に固定しています。合成ページでは動画別保存、失敗時の保全、CSV、ボタンセットJSON、再起動、狭幅などを確認済みです。

このZIPの実YouTube上での保存、動画間SPA遷移、全画面・シアター、字幕、広告との共存、Macの通常操作による最終確認は未完了です。モバイル版YouTube、Shorts、埋め込みプレーヤーは対応対象に含めていません。Google Sheets連携、クラウド同期、CSVからの記録復元はありません。
