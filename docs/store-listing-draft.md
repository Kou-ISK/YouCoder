- 名前: YouCoder
- 開発者の公開名: Kou Isaka (Kou-ISK)

- 言語: 日本語
- カテゴリ候補: 仕事効率化（提出時の選択肢を確認）
- ホームページ: https://github.com/Kou-ISK/YouCoder

- プライバシーURL候補: https://github.com/Kou-ISK/YouCoder/blob/develop/docs/privacy.md （マージ後の匿名アクセスを確認し、草案表示を正式版にしてから指定）

説明本文の案:

> YouCoderは、YouTubeの通常の動画ページで、チームごとのアクション開始・終了時刻とラベルを記録するChrome拡張機能です。プレーヤー下のタグ付けパネルとタイムラインで分析し、記録した時刻へ移動できます。ボタンセットを編集してJSONで受け渡し、動画ごとの記録をCSVで書き出せます。記録はこのブラウザーに保存されます。全データのクラウド同期・復元やGoogle Sheets連携はありません。

実サイト検証が終わるまで「字幕・広告を妨げない」「全画面・全YouTubeレイアウト対応」「安全性完全準拠」といった表現は追加しません。Shorts、埋め込みプレーヤー、モバイルアプリ対応も申告しません。

## Privacy practices の入力案

単一目的: **YouTube動画のスポーツ分析のため、利用者が付けたアクション区間とラベルを動画ごとに保存し、見返し・CSV出力できるようにする。**

| 宣言済み権限 | 理由の案 / 最終確認 |
| --- | --- |
| `storage` | ボタン設定・チーム一覧・表示設定・動画別タグ付け記録を端末内に保存し、タブや再起動後も利用するため |
| `unlimitedStorage` | 複数動画の記録を蓄積し、旧形式の移行用コピーも保持するため。10MB超の実利用・容量試験は未実施。最小権限の観点から継続の必要性を提出前に評価し、不要なら別変更で削除・保存失敗試験を行う |
| `https://www.youtube.com/*` | YouTube動画ページへUIを挿入し、動画IDと再生時刻を読み、記録した時刻へ移動するため。YouTube内のSPA遷移を扱うためにサイト全体へcontent scriptを登録している |

新規権限、`identity`、`cookies`、`history`、`tabs`、`downloads`、Google APIのホスト権限は追加していません。CSV/JSONはBlobとリンク操作による保存です。

リモートコード: **「使用していない」候補**。本番パッケージでは実行コードを同梱し、未使用のSheetsスクリプト読込試作は削除しました。最終ZIPを再監査してから確定します。開発ビルドのHMRは提出対象外です。

ローカル処理も開示対象です。「外部送信しないので収集データなし」と一括判断しません。[Chrome公式のデータ取扱いFAQ](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)に従い、次の候補を現行Dashboardの定義と照合します。

| データ分類候補 | 実装上の事実・申告案 |
| --- | --- |
| ウェブ履歴 (Web history) | 分析する動画IDを保存し、現在の動画URLを読む。対象として申告する案。全履歴の取得ではない |
| ユーザーのアクティビティ (User activity) | 利用者のタグ付け操作、開始/終了時刻、設定選択を扱う。対象として申告する案 |
| ウェブサイトのコンテンツ (Website content) | 動画ページのDOM、動画ID・再生位置/状態を読み、入力された分析記録を扱う。対象として申告する案。映像ファイルや字幕本文を収集する機能はない |
| 個人を特定できる情報 | 本人情報の専用入力欄はないが、チーム名・自由入力ラベルに人名等が入る可能性がある。自由入力の扱いを含めて最終判断が必要。「一切扱わない」と断定しない |
| 健康・財務/支払・認証・個人的通信・位置情報 | これらを取得する機能や専用入力欄はない。自由入力に機微情報を書かないよう説明する |

データ利用の認証文（販売しない、単一目的以外に転送しない、信用判定に使わない等）は、コード確認に加え発行者の運用上の約束を含みます。公開主体が最終確認してチェックする項目として残します。

[Chrome公式の申告手順](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)では目的・必要権限・リモートコード・データ利用とprivacy URLの整合を求めています。保存データの暗号化はアプリに未実装であり、[FAQの安全な取扱い要件](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)との整合も提出前の確認事項です。この草案は適合性の認証ではありません。
