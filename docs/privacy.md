# YouCoderのデータの取扱い

更新日: 2026-10-15。対象: [GitHub配布版0.0.2](../downloads/README.md)。開発者: **Kou Isaka (Kou-ISK)**。配布コードで確認した保存・通信・削除の動作を説明します。

## 扱う情報と目的

YouCoderはYouTube動画のアクション区間とラベルを記録し、見返し・CSV出力に使う拡張機能です。

| 情報 | 用途・保存先 |
| --- | --- |
| 開いている動画のURL中の動画ID、動画要素の再生位置・状態 | 動画ごとの記録と時刻移動。動画IDは保存キーに使い、開始/終了時刻はミリ秒で保存します。再生状態は画面動作に使います |
| 行ID、チーム名、アクション名、開始/終了時刻、ラベル | `chrome.storage.local` に保存。旧形式の記録も移行用に残る場合があります |
| ボタンセット、チーム一覧、選択状態、表示設定、読み込んだボタンセットJSON | `chrome.storage.local` に保存して設定に使います |
| パネルの位置・サイズ | `https://www.youtube.com` の `localStorage` に保存。YouTubeページのスクリプトからもアクセス可能な領域です。タイムライン記録はこの領域へ保存しません |
| 操作やエラーに関するログ | ブラウザーのローカルコンソール。本番ではエラーURL・再生状態等が含まれる場合があります。設定値・入力名をまとめて出すpopupのinfoログは開発時限定に変更しました。エラー内容に入力の断片が含まれる可能性はあります。ログ送信用の機能はありません |

YouTubeへのログイン情報、Cookie、パスワード、ブラウザー全体の履歴を読む機能はありません。ただし、保存された動画IDからどの動画を分析したか分かります。入力欄に個人名などを記入すれば、その文字列も記録に含まれます。

## 外部通信・共有

現行ソースと依存ライブラリを含む本番JavaScriptを監査した範囲では、記録・設定を開発者のサーバー、解析サービス、Google Sheetsへ送る処理や、拡張機能のアカウント・OAuth・広告配信機能は確認されていません。動的な通信をあらゆる環境で網羅した保証ではありません。監査範囲は[データフロー監査](data-flow-audit.md)に記載しています。

YouTubeの再生・広告・字幕などの通常通信と、Chrome自身の通信はそれぞれのサービスにより行われます。YouCoderはこれらを遮断するものではありません。パネル配置を保存するサイト領域はYouTubeと共有されます。

CSVやボタンセットJSONは、利用者が操作するとブラウザー経由でローカルファイルとして書き出されます。ファイルを他者へ送る、クラウドフォルダーへ保存する、コンソールログを報告するなどの共有は利用者の操作です。拡張機能には記録の販売、広告目的の転送、信用評価への利用を行う処理はありません。

## 保存期間・削除・バックアップ

自動削除期限はありません。現在のタイムライン行は画面で削除できますが、移行前の `timelines` コピーはその操作では消えません。全ての拡張機能保存データは拡張機能の削除で消えます。これはChromeの[ローカル保存領域の仕様](https://developer.chrome.com/docs/extensions/reference/api/storage)に基づきます。

YouTubeサイトに残る配置は拡張機能の削除とは別です。削除する場合はYouTubeのDevToolsのApplication → Local Storageで、`youCoder.panelLayout.v2` と、存在すれば旧キー `taggingPanel_position` / `taggingPanel_size` / `timelinePanel_position` / `timelinePanel_size` のみを選んで削除します。他のYouTube設定を消さないようにしてください。ダウンロードしたファイル、手動バックアップ、コピーしたログは利用者が別途削除します。

全記録を復元するUIやクラウド同期はありません。上級者向けの新規プロファイルへの復元は[手順と制約](backup-restore.md)を参照してください。[READMEのバックアップ手順](../README.md#バックアップと移行)を参照してください。アンインストール前に必要な記録を書き出してください。

## 保護の範囲

拡張機能内で保存データやエクスポートファイルを暗号化する機能はありません。端末・ブラウザープロファイル・バックアップ先へアクセスできる人からの保護を保証するものではありません。機密情報や不要な個人情報は入力しないでください。

## 問い合わせ・変更

[YouCoderのGitHub Issues](https://github.com/Kou-ISK/YouCoder/issues)で、個人情報を除いた質問や不具合を受け付けます。Issueは公開されるため、バックアップJSON、非公開の動画ID、個人名、認証情報は添付しないでください。

保存・通信・権限の動作を変更する場合は、この文書と配布版の説明を更新します。
