# YouCoder

YouTube動画を見ながら、チームごとのアクション区間とラベルを記録し、CSVで書き出すChrome拡張機能です。開発者: **Kou Isaka (Kou-ISK)**。

GitHubからダウンロードして使う試用版です。**Node.jsやビルドは不要**です。デスクトップ版Chromeの開発者モードで読み込みます。Chrome Web Storeへの提出・公開は行っていません。

**[YouCoder 0.0.2 のZIPをダウンロード](downloads/youcoder-0.0.2-chrome.zip?raw=true)** · [詳しい導入・更新手順](docs/install-from-github.md) · [配布物と検証範囲](downloads/README.md)

実YouTubeでの動画別保存・SPA遷移・字幕・広告・全画面の最終確認は未完了です。まず重要な記録を持たないChromeプロファイルで試してください。合成ページのMV3テスト成功を、実YouTubeの動作保証とは扱っていません。

## 導入

1. 上の配布ZIPをダウンロードし、展開します。GitHubの「Code → Download ZIP」はソースコード用なので、上のリンクを使ってください。
2. 展開した中の **`manifest.json` が直接入っているフォルダ**を、今後も使う固定の場所へ移します。例: 書類フォルダ内の `YouCoder`。読み込み後は移動・削除しないでください。
3. Chromeのアドレスバーに `chrome://extensions` と入力し、右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」で、手順2のフォルダを選びます。ZIPファイル自体は選びません。
5. 拡張機能一覧に **YouCoder 0.0.2** が出ることを確認します。ツールバーのパズル形アイコンからYouCoderを開き、チームとボタンセットを設定します。
6. 通常の `https://www.youtube.com/watch?v=...` 動画ページを開きます。既に開いていたページは再読み込みします。

権限は**YouTubeページの読み取り・変更**と**設定・記録の端末内保存**です。その他のサイト、履歴全体、Cookie、Google Sheetsの権限は要求しません。表示される権限がこの説明と違う場合は、配布元とファイルを確認してください。

更新は手動です。先に[バックアップ](#バックアップと移行)を取り、[更新手順](docs/install-from-github.md#更新する)に従って**同じフォルダの中身**を新しい配布物へ入れ替え、拡張機能の「再読み込み」を使います。アンインストールすると保存データは失われます。別フォルダ・別プロファイルでは拡張機能IDが変わる場合があり、記録は自動では引き継がれません。

## 使い方

- ポップアップでチーム、アクション、ラベル、ボタンセットを編集します。初期セットはサッカーとバスケットボールです。
- 動画を読み込んでから、タグ付けパネルでアクションの開始・終了を記録し、進行中の区間にラベルを付けます。記録は動画IDごとに保存されます。
- タイムラインで記録を確認し、該当時刻への移動や削除を行います。「CSV出力」で現在の動画のタイムラインを保存できます。
- ポップアップの「エクスポート」は**選択中のボタンセット1個**を保存します。「インポート」で追加でき、同名セットは確認後に上書きします。チーム一覧やタイムラインの復元には使えません。

タグ付け・タイムラインは、対応する通常動画ページのプレーヤー下に配置します。対応領域が見つからないページでは表示しません。見出しのドラッグ、右下ハンドル、ハンドルにフォーカスして矢印キーで配置を調整できます。「配置をリセット」「パネルを折りたたむ」も利用できます。

幅の広い領域と狭い領域の配置は別々に保存します。移動・サイズ変更後に隣のパネルを調整して重なりを防ぎ、必要な空きがなければ直前の配置を保ちます。ドラッグ中のプレビューは一時的に重なる場合があります。合成ページの320/375px操作を検証していますが、実YouTubeの字幕・広告・全画面・シアター・SPA遷移の確認は未完了であり、広告や字幕を妨げないことを保証する段階ではありません。

## バックアップと移行

自動クラウド同期、全動画一括エクスポート、全データ復元、CSVインポート、Google Sheets連携はありません。

| 方法 | 保存するもの | 復元・注意点 |
| --- | --- | --- |
| ボタンセットごとにJSONエクスポート | 選択中セットの名前・アクション・ラベル設定 | JSONインポートで復元可能。必要な各セットを別々に保存する |
| 動画ごとにCSVエクスポート | その動画の全タイムライン行。チーム・アクション・秒単位の開始/終了・ラベル | 分析用。動画ID・行IDは含まず、アプリへの復元は不可。動画IDをファイル名や別メモに残す |
| チーム一覧の手控え | チーム名 | 新しい環境で手動で作り直す |
| 上級者向けストレージJSON退避 | 旧形式を含む拡張機能ストレージ全体 | 下記の読み取り専用手順。復元UIはありません。新しい空のプロファイルへの上級者向け復元は[専用手順](docs/backup-restore.md)を参照 |

CSVの名前は `actions_YYYY-MM-DD.csv` です。同日に複数動画を保存する場合は動画IDなどを追記して区別してください。式として解釈される可能性のあるCSVセルには先頭の `'` が加わるため、元データの完全な復元形式ではありません。

ストレージ全体を退避したい場合は `chrome://extensions` のYouCoder詳細から **service workerの検証**を開き、YouCoderのDevToolsコンソールで次の読み取りだけを実行します。クリップボードをローカルのUTF-8テキストファイルへ貼り付け、`.json` で保存します。公開Issueへ貼り付けないでください。

```js
copy(JSON.stringify(await chrome.storage.local.get(null), null, 2))
```

このJSONには動画ID、入力した名称、移行前の記録も含まれ得ます。動画の操作を止めてから退避してください。これはYouTubeサイト側のパネル配置を含みません。配置は失われても再設定できます。クリップボードや保存ファイルを共有・同期する場合の扱いは利用者が確認してください。

旧版の `timelines[動画ID]` は、その動画を新バージョンで開いたときに `youCoder.timeline.<動画ID>` へコピーされ、行に永続IDが付きます。旧データは保全のため残します。既に新形式がある場合はそちらを使います。不正なデータや保存エラーがある場合は勝手に消さずエラーを表示します。エラー時に再インストールやストレージ消去で対処せず、バックアップを保持してください。

旧版の画面全体を基準としたパネル配置は引き継ぎません。新しい安全な初期配置から始めます。タイムラインを新形式で編集・削除しても旧 `timelines` は更新されないため、旧版へ戻すと古い記録が見える場合があります。アンインストールや旧形式の削除を伴う移行は、復元を確認できるまで行わないでください。

## 保存容量

API権限は `storage`、ホスト権限はYouTube HTTPSだけです。`unlimitedStorage` は削除しました。拡張機能のローカル保存上限は10,485,760 bytesで、移行前のコピーと設定も合算されます。合成の10,000行は約1.13MBでしたが、名称・ラベルの長さで変わります。上限や端末の問題で保存に失敗した場合は成功扱いにせず、既存記録を残します。

旧版で既に上限を超えるデータを持つ場合、更新後の追加・編集が拒否されます。更新前にバックアップと容量確認を行ってください。自動削除はしません。復元ファイルも上限内に収まる必要があります。[容量と復元の手順](docs/backup-restore.md)を参照してください。

## 保存とプライバシー

動画ID、タグ付け記録、設定は `chrome.storage.local`、パネルの位置・サイズはYouTubeサイトの `localStorage` に保存します。後者はYouTubeページと共有する保存領域です。現行の本番コード・依存を含む配布JavaScriptの監査では、記録を開発者サーバーやSheetsへアップロードする処理は見つかっていません。YouTube・Chrome自身の通信や、ローカルに保存したファイルの共有まで停止するものではありません。

削除・保存期間・ログ・権限の説明は[プライバシー文書](docs/privacy.md)、実装根拠は[データフロー監査](docs/data-flow-audit.md)を参照してください。

## 開発・検証

ソースを変更する場合だけ、Node.js **22.x** と pnpm **9.15.9** を使ってビルドします。ソースの最新状態と、上の固定版ZIPの内容は別です。ZIPの元コミットは[配布記録](downloads/README.md)で確認できます。

```bash
git clone https://github.com/Kou-ISK/YouCoder.git
cd YouCoder
git switch develop
pnpm install --frozen-lockfile
pnpm dev # 開発用。build/chrome-mv3-dev を読み込む
pnpm test:ci --runInBand
pnpm exec tsc --noEmit
pnpm build
```

本番確認には `chrome-mv3-prod` を使います。開発用ビルドはHMR等の開発機能を含みます。[実MV3検証の実行方法](scripts/mv3/README.md)も参照してください。

主なファイル: `popup.tsx`（設定）、`content.tsx`（動画ページUI）、`background.ts`（保存要求）、`lib/timelineStore.ts`（保存・移行）、`lib/actionCsv.ts`（CSV）、`components/AnalysisWorkspace/`（配置）、`assets/`（アイコン）、`docs/`（記録）。Plasmo 0.90.5 / React 18.2 / TypeScriptを使用しています。

不具合報告は[GitHub Issues](https://github.com/Kou-ISK/YouCoder/issues)へ。動画ID・チーム名・記録・コンソールログなどの個人情報や非公開情報は取り除いてください。
